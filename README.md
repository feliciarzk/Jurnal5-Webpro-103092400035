TUGAS PRAKTIKUM 5

1.	Pengertian Bootstrap [10 poin] 
Jelaskan apa itu Bootstrap dan apa kegunaannya!
Jawab: Bootstrap adalah framework CSS yang digunakan untuk mempermudah pembuatan tampilan website. Bootstrap menyediakan berbagai class dan komponen siap pakai, seperti tombol, navbar, form, dan card. Dengan Bootstrap, kita bisa membuat website yang rapi, menarik, dan responsif tanpa harus menulis banyak kode CSS dari awal.

2.	Memasang Bootstrap [10 poin] 
Ada beberapa cara untuk mengimpor atau menggunakan Bootstrap pada project. Sebutkan cara caranya!
Jawab: 
Bootstrap bisa digunakan dengan beberapa cara, yaitu:
•	CDN, dengan menambahkan link CSS dan JavaScript Bootstrap ke dalam file HTML.
•	Download, dengan mengunduh file Bootstrap dan menyimpannya di folder proyek.
•	NPM, dengan memasang Bootstrap menggunakan perintah npm install bootstrap.


3.	Grid dan Breakpoint [10 poin] 
Jelaskan mengenai class grid dan kegunaan breakpoint!
Jawab: 
Grid adalah sistem yang digunakan Bootstrap untuk mengatur tata letak elemen website agar tersusun rapi. Sistem grid Bootstrap terdiri dari 12 kolom yang bisa dibagi sesuai kebutuhan. 
Breakpoint adalah batas ukuran layar yang digunakan untuk menyesuaikan tampilan website pada perangkat yang berbeda. Bootstrap memiliki breakpoint sm, md, lg, xl, dan xxl. Dengan grid dan breakpoint, tampilan website bisa menyesuaikan ukuran layar komputer, tablet, maupun HP.
 4.	Class Bootstrap [10 poin] 
Sebutkan minimal lima class yang disediakan oleh Bootstrap beserta kegunaannya!
Jawab: 
Berikut beberapa class Bootstrap beserta kegunaannya:
•	.container untuk mengatur wadah konten.
•	.row untuk membuat baris pada grid.
•	.col untuk membagi area menjadi beberapa kolom.
•	.text-center untuk membuat teks rata tengah.
•	.bg-success untuk memberikan warna latar belakang hijau.
•	.btn untuk memberikan tampilan pada tombol.
•	.form-control untuk mempercantik tampilan input.
•	.d-flex untuk mengatur tata letak menggunakan Flexbox.
•	.mt-3 untuk memberikan jarak di bagian atas elemen.
•	.shadow untuk memberikan efek bayangan pada elemen.
